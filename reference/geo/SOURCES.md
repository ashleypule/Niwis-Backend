# Boundary data sources

All files in this folder are generated by `npm run geo -- <raw-dir>` (`scripts/build-geo.mjs`) from the raw downloads below, simplified with mapshaper. Coordinates are WGS84 (EPSG:4326).

| File | Content | Source | Licence |
|---|---|---|---|
| `provinces.json` | 9 provinces (`id` = EC, FS, GP, KZN, LP, MP, NC, NW, WC) | geoBoundaries gbOpen ZAF ADM1 (OCHA ROSEA / Municipal Demarcation Board, 2020) — https://www.geoboundaries.org/api/current/gbOpen/ZAF/ADM1/ | CC BY 3.0 IGO |
| `south-africa.json` | National outline (dissolved provinces; Lesotho is a hole) | derived from `provinces.json` | CC BY 3.0 IGO |
| `municipalities.json` | 213 local/metropolitan municipalities, tagged with `province` by inner point | geoBoundaries gbOpen ZAF ADM3 — https://www.geoboundaries.org/api/current/gbOpen/ZAF/ADM3/ | CC BY 3.0 IGO |
| `wmas.json` | 9 Water Management Areas (2012 delineation, as used in the NIWIS mockups) | DWS NWRP map service, layer 5 `WMA_New` — https://gia.dws.gov.za/hosting/rest/services/Map/NWRP/MapServer/5 | DWS public GIS service; attribute "Department of Water and Sanitation". Confirm the licence with DWS GIS before public release. |
| `catchments.json` | 100 secondary drainage regions (A1 … X4) | DWS NWRP map service, layer 11 — https://gia.dws.gov.za/hosting/rest/services/Map/NWRP/MapServer/11 | As above |
| `neighbours.json` | Namibia, Botswana, Zimbabwe, Mozambique, Lesotho, Eswatini | geoBoundaries gbOpen ADM0 for NAM, BWA, ZWE, MOZ, LSO, SWZ | CC BY 3.0 IGO / CC BY 4.0 (per country metadata) |
| `rivers.json` | Major rivers (scalerank ≤ 9), clipped to the region | Natural Earth 10m `rivers_lake_centerlines` | Public domain |
| `towns.json` | Major towns and cities | Natural Earth 10m `populated_places_simple` | Public domain |

Attribution shown in the map footer: "Boundaries: MDB/OCHA via geoBoundaries (CC BY), DWS; rivers/towns: Natural Earth".

**Note:** the 2023 NWRS-III gazette consolidated South Africa into 6 WMAs. The mockups (and this build) use the 9-WMA 2012 delineation. Switch `wmas.json` to the DWS `Water_Management_Areas_2023` service if DWS confirms the 6-WMA layout should be used.
